**Câu 1: A**
Ta có $\overrightarrow{MA} + 3\overrightarrow{MB} = \vec{0} \Rightarrow M$ là điểm chia đoạn $AB$ theo tỷ số $-3$.
Tọa độ điểm $M(x_M; y_M; z_M)$ thỏa mãn:
$$x_M = \dfrac{x_A + 3x_B}{1+3} = \dfrac{2 + 3(2)}{4} = 2$$
$$y_M = \dfrac{y_A + 3y_B}{1+3} = \dfrac{2 + 3(-2)}{4} = -1$$
$$z_M = \dfrac{z_A + 3z_B}{1+3} = \dfrac{3 + 3(-1)}{4} = 0$$
Vậy tọa độ điểm $M$ là $(2; -1; 0)$. Chọn **A**.

**Câu 2: B**
Với số thực $a > 0$, ta có:
$$\log(1000a) = \log 1000 + \log a = \log(10^3) + \log a = 3 + \log a$$
Chọn **B**.
