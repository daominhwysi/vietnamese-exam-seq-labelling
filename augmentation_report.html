2. Recommended Augmentation Methods

Specific transformation techniques engineered for Vietnamese Educational Exam Papers.

Method A • Critical Prob: 0.15 - 0.25

Whitespace Removal & Compaction

Removes spaces after colons, periods, or compresses multi-space tab separators. Real OCR papers often lack whitespace between prefixes and stems.

// Baseline Layout:
Câu 1: Cho hàm số f(x)... \n A. Đáp án 1 \n B. Đáp án 2
// Compacted OCR Layout:
Câu 1:Cho hàm số f(x)... A.Đáp án 1 B.Đáp án 2
Token Benefit: Prevents Byte-Level BPE from switching tag predictions when leading whitespace bytes (Ġ) are omitted.
Method B • High Value Prob: 0.10 - 0.20

Delimiter & Punctuation Perturbations

Randomly alternates delimiter characters (quotes ", dots ., colons :, dashes -, parentheses )) on question and option labels.

// Delimiter Style Permutations:
"Câu 1." ↔ "Câu 1:" ↔ "Câu 1 -" ↔ "1." ↔ "1)" ↔ "Q1."
"A." ↔ "A)" ↔ "A:" ↔ "a." ↔ "**A.**" ↔ "a)" ↔ "A -"
Token Benefit: Stops the sequence labeler from memorizing static period . anchors as the only prefix boundary marker.
Method C • Critical Prob: 0.15 - 0.20

Option & Label Dropout

Randomly drops 1–2 options (simulating True/False with 2 choices or OCR omission), or drops the option_label prefix entirely (simulating table cells with pure option text).

// True/False 2-Choice Dropout:
a) Đồ thị hàm số đi qua gốc O. \n b) Hàm số nghịch biến.
// Label-less Table Cells:
<option_text>Fe</option_text> | <option_text>Cu</option_text>
Token Benefit: Breaks inductive bias where the model assumes every question must have exactly 4 choices (A, B, C, D).
Method D • High Value Prob: 0.20 - 0.35

LaTeX Masking & Formatting Noise

Randomly replaces mathematical formulas with [LATEX] placeholder, alters math delimiters ($...$ ↔ \(...\)), and wraps stems in markdown tags (**, ).

// Math Formula Masking:
Cho $x^2 + y^2 = 1$ ↔ Cho [LATEX] có tâm O
// Markdown Underline/Bold Tagging:
<stem>Choose the word with <u>different</u> sound:</stem>
Token Benefit: Prevents complex mathematical subword formulas from consuming sequence length while preserving span positions.

4. PyTorch Online Dataset Implementation

Drop-in PyTorch Dataset class connecting reconstructor.py with align_tokens_to_spans().

import torch
import random
from torch.utils.data import Dataset, DataLoader
from src.generation.reconstructor import reconstruct_question, ReconstructorConfig
from src.data.prepare import align_tokens_to_spans

class OnlineAugmentedExamDataset(Dataset):
    def __init__(self, raw_questions: list, tokenizer, tag_to_id: dict, max_length: int = 1024):
        self.raw_questions = raw_questions
        self.tokenizer = tokenizer
        self.tag_to_id = tag_to_id
        self.max_length = max_length

    def __len__(self):
        return len(self.raw_questions)

    def __getitem__(self, idx):
        q_data = self.raw_questions[idx]

        # 1. Stochastic Augmentation Config per sample per epoch
        aug_config = ReconstructorConfig(
            question_prefix_template=random.choice([
                "Câu {num}: ", "Câu {num}. ", "Câu {num}:", "{num}. ", "{num}) "
            ]),
            option_prefix_style=random.choice([
                "capital_dot", "lowercase_paren", "bold_capital_dot", "capital_paren"
            ]),
            separator_stem_options=random.choice(["\n", " ", "\n\n"]),
            separator_options=random.choice(["\n", "    ", "\t\t"]),
            option_drop_prob=0.15,
            space_noise_rate=0.10,
            formatting_noise_prob=0.10,
            typo_rate=0.02,
            latex_mask_prob=0.30,
            randomize_q_num=True
        )

        # 2. Reconstruct raw text + exact synchronized character spans
        reconstructed = reconstruct_question(q_data, config=aug_config)
        raw_text = reconstructed["raw_text"]
        spans = reconstructed["spans"]

        # 3. Fast Tokenization
        tokenized = self.tokenizer(
            raw_text,
            return_offsets_mapping=True,
            truncation=True,
            max_length=self.max_length,
            add_special_tokens=True
        )

        # 4. BIO Label Alignment
        labels = align_tokens_to_spans(
            tokenized["offset_mapping"],
            spans,
            self.tag_to_id,
            raw_text=raw_text
        )

        return {
            "input_ids": torch.tensor(tokenized["input_ids"], dtype=torch.long),
            "attention_mask": torch.tensor(tokenized["attention_mask"], dtype=torch.long),
            "labels": torch.tensor(labels, dtype=torch.long)
        }

# Optimal DataLoader Initialization
loader = DataLoader(
    dataset=OnlineAugmentedExamDataset(raw_questions, tokenizer, tag_to_id),
    batch_size=8,
    shuffle=True,
    num_workers=4,            # Enables 4 asynchronous background CPU workers
    prefetch_factor=2,        # Pre-buffers batches in memory
    pin_memory=True
)
